# نسخه جدید انبار ستاره

این بسته یک برنامه مستقل و سبک برای موجودی انبار ستاره است؛ ظاهر قرمز و شناسه انبار `setareh` حفظ شده است.

## فایل‌ها
- `index.html`: برنامه
- `cloud-config.js`: آدرس پروژه و کلید عمومی Supabase
- `sw.js` و `manifest.json`: نصب PWA و cache پایه
- `SUPABASE_SETUP.sql`: سیاست‌های دسترسی پایگاه داده

## راه‌اندازی
1. از فایل‌های فعلی مخزن یک کپی نگه دارید؛ این بسته جایگزین برنامه بزرگ قبلی است و امکانات حواله، گزارش‌های قدیمی و امضاها را ندارد.
2. محتویات ZIP را در مخزن جداگانه/شاخه آزمایشی بارگذاری کنید و مطمئن شوید فایل‌ها در ریشه مخزن باشند.
3. در Supabase > SQL Editor، ساختار جدول‌ها را با توضیحات ابتدای `SUPABASE_SETUP.sql` تطبیق دهید و سپس SQL را اجرا کنید. اگر ستون یا نوعی متفاوت است، پیش از اجرا باید SQL متناسب شود.
4. در Supabase Authentication > Users برای هر شخص حساب بسازید. حساب مدیر و حساب‌های محمد و حمید باید با ایمیل‌های واقعی خودشان ایجاد شوند.
5. شناسه UUID هر حساب را از Authentication > Users بردارید و در جدول `warehouse_memberships` ثبت کنید:
   - مدیر: `warehouse_id = setareh`, `role = manager`
   - محمد و حمید: `warehouse_id = setareh`, `role = viewer`
   - ستون `user_id` باید UUID همان حساب باشد.
6. فقط پس از ثبت عضویت‌ها، برنامه را از طریق HTTPS باز کنید و با هر حساب جداگانه آزمایش کنید.

## نکات امنیتی و محدودیت‌ها
- کلید موجود در `cloud-config.js` کلید عمومی است؛ هرگز service_role یا secret را در مرورگر قرار ندهید.
- کنترل مجوز واقعی با RLS در Supabase انجام می‌شود؛ پنهان‌کردن دکمه‌ها به‌تنهایی امنیت نیست.
- کاربران viewer فقط `warehouse_inventory` را می‌خوانند. برای آن‌ها هیچ عملیات تغییر/حذف/چاپ/خروجی در رابط برنامه وجود ندارد.
- گرفتن اسکرین‌شات از صفحه توسط سیستم‌عامل قابل جلوگیری نیست.
- این نسخه از `warehouse_private_state` استفاده نمی‌کند و داده‌های کامل خصوصی برنامه قبلی را دانلود نمی‌کند.
- cache آفلاین فقط پوسته برنامه و آخرین فهرست موجودی دریافت‌شده روی همان دستگاه را نگه می‌دارد. ورود و تازه‌سازی موجودی برای اتصال به اینترنت نیاز دارد. کتابخانه Supabase از CDN بارگیری می‌شود؛ اجرای آفلاین در اولین بازدید تضمین نیست.
- این نسخه، جایگزین کامل برنامه قبلی ۳۵۰۰ خطی نیست؛ حواله‌ها، گزارش‌ها، امضاها، تنظیمات و داده‌های localStorage قدیمی را منتقل نمی‌کند. پیش از جایگزینی نسخه عملیاتی، قابلیت‌ها و داده‌ها را بررسی کنید.
