انبار ستاره — بسته کامل برنامه با اصلاح کش آفلاین

محتوای این بسته:
- نسخه اصلی برنامه و ساختار کامل آن حفظ شده است.
- کلید داده محلی setareh_v5 تغییر نکرده است.
- اتصال Supabase و کنترل نقش manager/viewer موجود در نسخه مبنا حفظ شده است.
- Service Worker به‌روزرسانی شده تا فایل‌های برنامه و کتابخانه‌های CDN که قبلاً با اینترنت بارگیری شده‌اند، در کش آفلاین نگهداری شوند.

نصب:
1) پیش از جایگزینی، از مخزن فعلی GitHub یک نسخه پشتیبان بگیر.
2) تمام فایل‌های این ZIP را مستقیماً در ریشه مخزن setareh-anbar-pwa قرار بده.
3) Commit و Deploy را انجام بده.
4) سایت را یک بار با اینترنت باز کن و صبر کن تا فایل‌ها بارگیری شوند؛ سپس حالت آفلاین را آزمایش کن.

محدودیت مهم:
این بسته از نظر ساختار فایل و نحو JavaScript بررسی شده، اما آزمون زنده روی حساب Supabase و سیاست‌های RLS انجام نشده است.
عملیات آنلاین به اینترنت نیاز دارند. حالت آفلاین فقط پوسته و فایل‌ها/کتابخانه‌هایی را که قبلاً بارگیری و کش شده‌اند در دسترس می‌گذارد؛ همگام‌سازی آفلاین تضمین نمی‌شود.
برای امنیت نهایی، باید تمام Policyهای قدیمی Supabase بازبینی شوند؛ مخفی‌کردن دکمه‌ها به‌تنهایی کنترل دسترسی محسوب نمی‌شود.
